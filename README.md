# 33PROJECT — VS Code version

## Open in Visual Studio Code
1. Extract this ZIP.
2. Open the `33PROJECT_VSCode` folder in Visual Studio Code.
   - Or double-click `33PROJECT.code-workspace`.

## Run the website

### Option A — From VS Code
1. Press `Ctrl + Shift + P`.
2. Search for `Tasks: Run Task`.
3. Choose `Run 33PROJECT Website`.
4. Open:
   http://localhost:5500

### Option B — Double-click
Double-click `start-server.bat`, then open:
http://localhost:5500

### Option C — Live Server extension
If you have the VS Code "Live Server" extension:
1. Open `index.html`.
2. Click `Go Live` at the bottom-right.

## Main file
- `index.html`

All HTML, CSS, and JavaScript are currently inside `index.html`, so you can edit everything from one file.
